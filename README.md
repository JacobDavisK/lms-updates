# Jacob Davis LMS — download and updates

**Current version: 1.4.2**

## Install (Windows 10 / 11)

1. Download **[Jacob-Davis-LMS-Setup.zip](https://github.com/JacobDavisK/lms-updates/raw/main/Jacob-Davis-LMS-Setup.zip)**.
2. Right-click the zip → **Extract All…**, open the folder and double-click **Install Jacob Davis LMS**.
3. Your browser opens with the LMS.

Nothing else needs to be installed and administrator rights are not needed.

## Updates

Installed copies check this page and update themselves when nobody is using the site.
Records stay on the computer where the LMS is installed; this page holds only the program.
